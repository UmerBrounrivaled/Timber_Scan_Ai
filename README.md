# TimberScan AI — Wood Defect & Anomaly Detection System

An end-to-end Deep Learning Industrial Inspection web application built with **React (Vite + Tailwind CSS)** and a **FastAPI** inference backend powered by a TensorFlow Autoencoder trained on the **MVTec Wood Anomaly Detection dataset**.

---

## 🌟 Key Features

1. **Dual Input Inspection Modes**:
   - **Upload Custom Images**: Drag-and-drop or select any wood photo with instant client-side preview, validation, and dimension checking.
   - **Benchmark Sample Library**: Curated pre-loaded test samples categorized into *Normal Wood Grain, Wood Knots, Surface Cracks, Perforation Holes, Scratches, and Discoloration Stains*.
2. **Interactive Visual Comparison Studio**:
   - **Interactive Split Slider**: Drag handle to smoothly wipe between the original raw wood grain and the AI anomaly blended overlay in real-time.
   - **AI Heatmap Overlay**: 60/40 blend of Jet thermal error colormap over the original image.
   - **Pure Thermal Map**: Standalone per-pixel reconstruction error heatmap.
   - **Autoencoder Reconstruction**: Synthesized clean reconstruction output generated by the neural network.
3. **Comprehensive Quality Metrics**:
   - Automated verdict: **DEFECT DETECTED** vs **DEFECT-FREE (PASSED)**.
   - Anomaly severity classification (*Pristine, Nominal, Minor Anomaly, Moderate Defect, Severe Defect*).
   - Mean Squared Error (MSE) score vs Youden's J Cutoff Threshold (`0.000637013`).
   - Score / Threshold anomaly ratio gauge.
   - Anomaly surface area percentage calculation and inference latency (ms).
4. **Inspection Reporting**:
   - Export printable Quality Inspection Reports.
   - Download high-resolution annotated inspection PNG images.
   - Export structured JSON diagnostic logs.

## 🚀 Getting Started

### 1. Prerequisites
- **Python 3.10+** (with `pip`)
- **Node.js 18+** & `npm`

### 2. Backend Setup
1. Open a terminal in the project root directory:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the FastAPI backend server:
   ```bash
   python -m uvicorn main:app --reload --port 8000
   ```
   *The backend will be available at `http://127.0.0.1:8000` (Swagger docs at `/docs`).*

### 3. Frontend Setup
1. Open a second terminal and navigate to `frontend/`:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```
